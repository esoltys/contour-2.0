# Contour Tutorial

Welcome to Contour! This tutorial will guide you from creating your first simple melody all the way to building complex, algorithmic compositions.

## Tutorial Parts

### [Part 1: Basics](tutorials/01-basics.md)
Learn the fundamentals: creating your first sounds, understanding core concepts, and building patterns.

- Hello World: Your First Sound
- Understanding Core Concepts (Events, Branded Types, Immutability)
- Building Patterns (Direct Construction, PatternBuilder, Array Shorthand)

### [Part 2: Mini-Notation](tutorials/02-notation.md)
Master Contour's concise pattern syntax inspired by TidalCycles.

- Basic Syntax
- Repetition, Rests, Subdivisions
- Longer Notes, Octave Persistence
- Chord Symbols

### [Part 3: Transformations](tutorials/03-transformations.md)
Transform patterns with functional operations and generate algorithmic rhythms.

- Pattern Transformations (Transpose, Fast/Slow, Retrograde, Map)
- Pattern Algebra (Stack, Append, Palindrome, Every)
- Euclidean Rhythms

### [Part 4: Compositions](tutorials/04-composition.md)
Build multi-track compositions and export your music.

- Creating Compositions
- Multiple Voices and Tracks
- Exporting to MIDI and Audio

### [Part 5: Advanced](tutorials/05-advanced.md)
Master advanced musical effects and techniques.

- Advanced Effects & Articulations
- Staccato, Legato, Dynamics
- Humanization, Swing, Tremolo
- Advanced Algorithmic Techniques

### [Part 6: Reference](tutorials/06-reference.md)
Quick reference guide and comparisons with other tools.

- Quick Reference
- Coming From Other Tools
- What's Next
